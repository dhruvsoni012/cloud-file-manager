# ☁️ Cloud File Manager

**Secure • Private • Zero-Knowledge Cloud Storage**

A simple, self-hosted cloud storage app where **only you can access your files** — not even the server.

---

## 🚀 Live Demo
👉 https://cloud-file-manager-hlj6.onrender.com/


---

## 🌟 Features

### 🔐 Security
- End-to-end encryption (AES-256)
- Zero-knowledge architecture
- Encrypted filenames & metadata
- Secure password hashing (bcrypt)

### 📁 File Management
- Upload files & folders  
- Drag & drop support  
- Search files instantly  
- Copy, move, rename, delete  
- Trash with recovery  

### 🎨 Interface
- Clean, responsive design  
- Dark & light mode  
- Works on mobile & desktop  

### 👑 Admin Features (Only for admin accounts)
- User management  
- Storage limits (quotas)  
- Activity logs  

---

## ⚡ Quick Start

1. Go to https://cloud-file-manager-hlj6.onrender.com/ 
2. Sign up 
3. Upload files  
4. Access them securely anytime  

---

## 🔒 How It Works

- Files are encrypted **before upload**  
- Server stores only encrypted data  
- Only you can decrypt your files  

---

## 🛠️ Tech Stack

- Backend: Python (Flask)  
- Database: PostgreSQL  
- Encryption: AES-256 (Cryptography)  
- Frontend: HTML, CSS, JavaScript  
- Hosting: Render.com  

---

## 📊 Why This?

- No data tracking  
- Full privacy  
- Self-hosted option  
- Free to use
